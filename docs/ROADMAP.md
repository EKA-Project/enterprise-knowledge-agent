# Enterprise Knowledge Assistant
## Learning & Development Roadmap

---

# Project Philosophy

This project is built using a simple philosophy:

> Learn → Build → Contribute → Repeat

Every new concept learned must immediately contribute to the Enterprise Knowledge Assistant.

Nothing will be learned "just because."
Every topic must answer two questions:

1. Why are we learning this?
2. How does it improve our project?

The project should always remain in a runnable state.
