# Enterprise Knowledge Assistant

An AI-powered Enterprise Knowledge Assistant that enables organizations to interact with internal documents using Generative AI, Retrieval-Augmented Generation (RAG), NLP, and Agentic AI.

🚧 Project Status:
Currently under development following a phase-by-phase learning roadmap.

Tech Stack (Planned)

- Python
- FastAPI
- React
- PostgreSQL
- ChromaDB
- Gemini API
- Docker
